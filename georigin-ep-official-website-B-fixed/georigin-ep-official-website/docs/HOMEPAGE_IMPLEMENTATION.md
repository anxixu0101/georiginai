## 预览

运行中的服务：http://127.0.0.1:3000/ 。已打开旧页面时刷新。

后续双击外层目录的 `预览网站.cmd`，或在项目目录执行：

```powershell
npm.cmd run dev -- --host 127.0.0.1
```

以终端实际 Local 地址为准，保留终端窗口。测试命令为 `npm.cmd test`。
